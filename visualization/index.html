Which coalition can block?

Select vertices of the cubic input graph. A selected vertex buys one 20-agent gadget. An uncovered edge has no selected endpoint.

Selected vertices

The four vertices stand for input vertices. Each selected vertex expands into two triangles joined by a bridge and a tether with 14 internal agents. Each input edge has its own pair of switch agents. The game uses mutual friendships of degree at most three. See the paper for the argument that every weak block pays for a whole gadget at some endpoint of every input edge.
